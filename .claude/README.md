# .claude

Working material for AI coding sessions on this repo. Nobody needs this
folder to run the pipeline.

| File | What it is |
|---|---|
| `../CLAUDE.md` | The standing rules. Read first, every session. |
| `skills/add-practice/SKILL.md` | Walkthrough for adding a practice to the vocabulary. |

Rules of the folder:

- Anything here is guidance for writing code, never analytical content. The
  vocabularies, the keyword list and the scope rules live in `catalogues/`
  and `R/00_shared/paths.R`, and are read at run time.
- If a rule here and a rule in `CLAUDE.md` disagree, `CLAUDE.md` wins.
